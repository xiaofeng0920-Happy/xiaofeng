**Proposed price: US$29. Status: collecting interest; not available to buy yet. No payment is requested and no release date is set.**

Do you repeatedly clean order CSV files and want to understand and run the workflow yourself?

The [Python source, tests and synthetic demonstration](../portfolio/csv-order-demo/) are already publicly viewable. The proposed paid pack would add practical materials for running and checking that demonstration:

- Bilingual English/Chinese run instructions and common-error guidance.
- A worksheet for column mapping, duplicate keys, sales statuses, amount meaning and currencies.
- An acceptance checklist with a row-by-row explanation of the 12 fictional example records.
- One written installation question within seven days of a future purchase, with the support scope agreed before sale.

## Fit and limits

You would need to install and run Python 3.11+ yourself. The current demo supports CSV with its documented fixed eight-column schema, up to 10,000 rows. The materials would explain that existing workflow; they would not add automatic support for arbitrary store exports. XLSX, custom schema implementation, new features, remote installation and processing real orders are separate service work.

This is a personal synthetic-data project. AI-assisted development and writing are reviewed and checked. Commercial-use and redistribution terms for any released materials would be stated before sale; this interest page grants no new license.
